# 🚀 GitHub Issue Creator (AI-Powered)

An interactive, AI-powered CLI tool that transforms raw issue notes and bug reports into structured, production-ready GitHub issues using **Google Gemini 2.5 Flash** and **PyGithub**, with support for local screenshot attachments.

---

## ✨ Features

- **🤖 AI-Powered Formatting**: Converts unstructured thoughts or bug notes into formal GitHub issues (Bug Reports, Feature Requests, Refactoring Tasks, etc.) using Google Gemini 2.5 Flash.
- **🖼️ Local Screenshot & Image Attachments**:
  - Attach any local image/screenshot directly from your PC.
  - **Multimodal AI Analysis**: Gemini visually inspects your screenshot to incorporate error dialogs, UI bugs, and visual context into the issue description.
  - **Automatic GitHub Hosting**: Uploads the attachment into the repository's `assets/issue_attachments/` directory and embeds the markdown preview link in the issue.
- **⚡ Interactive Terminal UI**: Built with `questionary`, `art`, and `simple_chalk` for a clean CLI experience with arrow-key navigation.
- **📂 Batch File or Manual Input**: Pick issues line-by-line from text files in `./issues/` or type descriptions on the fly.
- **👥 Collaborator & Label Integration**:
  - Automatically fetches labels from your target GitHub repository and matches them.
  - Allows selecting assignees from existing repository collaborators.
- **💾 Local Draft Backup**: Automatically saves every generated issue draft to `./out/issue_<title>_<timestamp>.txt`.
- **🔐 Secure Token Management**: Stores tokens locally in `./creds/` (ignored by Git) for quick reuse across sessions.

## 🛠️ Prerequisites

1. **Python 3.10+**
2. **GitHub Personal Access Token (Classic or Fine-Grained)**:
   - Needs `repo` scope (to read repositories, create issues, and commit image attachments).
   - Generate one at: [GitHub Settings > Developer Settings > Personal Access Tokens](https://github.com/settings/tokens).
3. **Google Gemini API Key**:
   - Free API key available at: [Google AI Studio](https://aistudio.google.com/).

## 📦 Installation

1. **Clone the repository**:
   ```bash
   git clone <your-repo-url>
   cd "GITHUB ISSUE"
   ```

2. **Create and activate a virtual environment**:
   ```bash
   # Windows PowerShell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1

   # Linux / macOS
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

## 🚀 How to Run

Launch the interactive CLI:

```bash
python .\app.py
```

### CLI Workflow:

1. **GitHub Authentication**: Enter or select your saved GitHub Personal Access Token.
2. **Repository Selection**: Choose from your available GitHub repositories using arrow keys.
3. **Issue Selection**: Select an issue file from `./issues/` (or type an issue manually).
4. **Attach Image (Optional)**: If you have a screenshot on your PC (e.g. `C:\path\to\error.png`), paste the path.
5. **AI Generation**: Gemini drafts a complete issue (title, type, labels, and Markdown body).
6. **Assignee Selection**: Pick a collaborator to assign the issue to (or choose `None`).
7. **Created**: The issue is created on GitHub, and the live issue URL is printed to the terminal!

## 📝 Preparing Issue Files

You can create `.txt` files inside the `./issues/` directory with multiple issue items (one per line):

```text
1. The login button is disabled on mobile Safari.
2. Add pagination to the user transactions table.
3. Database connection timeout occurs under heavy query load.
```

The CLI will parse these line-by-line, allowing you to select which one to generate and post to GitHub.

## 🔒 Security & Git Ignore

- The `.gitignore` file is configured to strictly exclude all sensitive credentials (`creds/`), generated drafts (`out/`), virtual environments (`.venv/`), and raw issue notes (`issues/`).
- Never commit your `creds/` directory or personal tokens to GitHub.
